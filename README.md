# Rishabh Kumar Portfolio

https://my-portfolio-uzer.onrender.com/

A responsive personal portfolio website built with plain HTML, CSS, and JavaScript.

It includes a custom hero section, animated section reveals, a floating education bar, a mobile sidebar navigation, interactive project cards, and decorative UI elements designed for a modern portfolio look.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Inter
- Cabinet Grotesk

## Project Structure

```text
Portfolio/
|-- index.html
|-- style.css
|-- script.js
|-- images/
```


## Main Sections

- Home
- About
- Education
- Skills
- Projects
- Contact

## Features

- Responsive layout for desktop and mobile
- Mobile hamburger menu with right-side sidebar
- Scroll-based active navbar highlighting
- India time-based greeting in the hero section
- Typing effect for hero text
- Floating orbit badge with hover interaction
- Decorative star, thunder, and wave accents
- Count-up animation in the education bar
- Project image hover cursor with `View More`
- Styled CTA buttons and social icons
- Scroll reveal animations across sections

## Files To Edit

### Content

Edit [index.html] to update:

- name and hero text
- about cards
- education details
- skills content
- project titles, descriptions, and links
- contact details

### Styling

Edit [style.css] to update:

- colors
- spacing
- typography
- layout
- animations
- mobile responsiveness

### Interactions

Edit [script.js] to update:

- typing effect speed and sequence
- greeting logic
- navbar active state behavior
- education counter animation
- project hover cursor behavior
- mobile menu toggle behavior

## External Assets

The site currently uses:

- Font Awesome for icons
- Google Fonts for `Inter`
- Fontshare for `Cabinet Grotesk`

These are loaded from CDNs in [index.html].

## Customization Notes

- Replace project image links with your own live/demo URLs if needed.
- Replace social links in the navbar and footer with your preferred platforms.
- Update images inside the `images/` folder as needed.
- If you change section ids, also update the navbar anchor links and scroll-tracking logic in [script.js].
