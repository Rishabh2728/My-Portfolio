# Rishabh Kumar Portfolio

A responsive personal portfolio website built with plain HTML, CSS, and JavaScript.

It includes a custom hero section, animated section reveals, a floating education bar, a mobile sidebar navigation, interactive project cards, and decorative UI elements designed for a modern portfolio look.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Inter
- Cabinet Grotesk

## Project Structure

```text
Portfolio/
|-- index.html
|-- style.css
|-- script.js
|-- images/
```

## Run Locally

This is a static website, so no build step is required.

1. Open [index.html](C:/Users/Rishabh/Desktop/Projects/Portfolio/index.html) directly in your browser.
2. Or use a local live server from your editor for easier preview while editing.

## Main Sections

- Home
- About
- Education
- Skills
- Projects
- Contact

## Features

- Responsive layout for desktop and mobile
- Mobile hamburger menu with right-side sidebar
- Scroll-based active navbar highlighting
- India time-based greeting in the hero section
- Typing effect for hero text
- Floating orbit badge with hover interaction
- Decorative star, thunder, and wave accents
- Count-up animation in the education bar
- Project image hover cursor with `View More`
- Styled CTA buttons and social icons
- Scroll reveal animations across sections
